Erudit Game (Эрудит)

Курсовой проект: реализация игры "Эрудит" на C# с использованием Windows Forms.

Описание

Программа представляет собой настольную игру "Эрудит", в которой игроки составляют слова из букв на игровом поле и получают очки.

Функционал

- Выбор количества игроков (2–4)
- Игровое поле с бонусными клетками (x2, x3)
- Генерация случайных букв (7 у каждого игрока)
- Проверка слов по словарю
- Подсчет очков с учетом стоимости букв
- Пропуск хода с заменой букв
- Определение победителя
- Стартовое меню

Архитектура проекта

Core:
- Board — игровое поле
- Tile — клетка поля
- Player — игрок
- LetterBag — генерация букв
- LetterScore — стоимость букв

UI:
- Form1 — игровое окно
- StartForm — стартовое меню

Запуск проекта

1. Открыть решение в Visual Studio
2. Запустить проект (F5)
3. Выбрать количество игроков
4. Начать игру
